# LRU Cache në Java

Implementim i politikës Least Recently Used me get dhe put në O(1).
Projekt grupor, Algoritme të Avancuara dhe Struktura të Dhënash.

## Struktura e planifikuar
- Cache.java: ndërfaqja (get, put, size)
- LRUCache.java: implementimi me HashMap dhe listë dyfishe
- Node.java: nyja e listës
- Main.java: testet dhe demonstrimi
